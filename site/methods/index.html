Methods

A small Nextflow DAG with frozen scientific identities

Harako-native owns the qualified Parabricks alignment contract; the shared controller owns versioned quantification, validation, matrices, and evidence.

Harako-native execution

  1. FASTP
    Fixed image and processed-pair contract.
  2. PARABRICKS_RNA_FQ2BAM
    Fixed one-/two-pass argv and exact process resources.
  3. PUBLISH_ALIGNMENT_CONTRACT
    Canonical backend-neutral output manifest.
  4. FEATURECOUNTS_BIOTYPE_QC
    GENCODE 49 uses -t exon -g gene_type.
  5. MULTIQC
    Bounded QC/report aggregation.

No hidden Salmon runs inside Nextflow. The controller maps the same processed paired FASTQ with explicit library type and six threads.

No free-form scientific arguments, global memory override, dynamic escalation, or CPU STAR fallback is accepted.

Counts and quantification

For the exact GRCh38.p14 / GENCODE 49 pack, FeatureCounts freezes feature type exon and group type gene_type. This is a biotype/QC artifact and is distinct from the STAR ReadsPerGene.out.tab comparator.

Salmon 2.5.1 is the deterministic default. Salmon 1.10.3 remains a visible bounded-numerical compatibility profile. Compare-both executes the two profiles sequentially against identical processed FASTQ. Each Run freezes the image, index, options, library type, thread count, order, and downstream primary profile.

Version-pinning claim: Without fixing the Salmon version, software-version-dependent numerical differences and method-dependent variation may be mixed with differences caused by experimental conditions. These differences include more than simple rounding error: they may depend on version, implementation, index, and execution behavior.

Immutable lifecycle and reference backend

The plan freezes backend, alignment/quantification profile, assets, images, outputs, resources, execution context, and approval identity. Prepare revalidates the frozen closure. Start/resume use structured argv with shell=False, atomic PID/lock/state, and numbered attempts. Completed runs do not resume. Deep artifact verification and support bundles use the same product services as the GUI.

nfcore_rnaseq_3_26_reference retains its pinned pipeline commit, patches, offline nf-schema@2.5.1 closure, and 18-image closure as a comparison/reference backend. Harako-native does not require nf-schema or the full runtime image closure.

Limitations

  • Public research alpha; research-only, non-diagnostic, non-clinical.
  • Exact host/reference qualification only; no arbitrary RTX, custom reference, or general FASTQ claim.
  • No CPU STAR, DESeq2, matched CPU speed benchmark, or claim that every workflow stage uses a GPU.
  • Automatic archive/delete is absent; successful terminal results may be explicitly archived after verification.
  • Actual Ubuntu browser runtime was unavailable during GUI qualification; AppTest, HTTP, and C1 product runs passed.
  • Cross-host equality and biological truth were not evaluated.
The evidence validates fixed engineering/scientific contracts and retained public inputs. It does not validate interpretation, experimental design, clinical performance, or arbitrary deployment.
