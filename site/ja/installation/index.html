研究用公開α版の導入

解析用データとホスト証明書も、実行条件の一部です

解析を始める前に、利用者または環境管理者が必要な項目を準備します。Harako-GPUがベンダー規約へ同意したり、レジストリへログインしたり、Runの準備中に解析用コンテナやデータをダウンロードしたりすることはありません。

検証済みの構成

OSWSLを介さずに動作するUbuntu 24.04.4 LTS
GPUNVIDIA GeForce RTX 3090、24 GiB VRAM、互換性のあるドライバー
メモリ128 GBの物理RAM
解析中の保存先必要な空き容量を確保したローカルext4 SSD。WD GoldやネットワークストレージをNextflowのworkDirには使用しません。
コンテナ実行環境Docker EngineとNVIDIA Container Toolkit
ワークフロー実行環境Java 17以降とNextflow 25.04.3
アプリケーションPython 3.11以降とHarako-GPU v0.1.0-alpha.1
アラインメント用イメージ取得元とバージョンを検証したParabricks 4.6.0-1。実行時のイメージIDも一致している必要があります。
参照データ固定したGRCh38.p14 / GENCODE 49参照パック、STAR 2.7.2aインデックス、選択したSalmon 2.5.1および／または1.10.3インデックス
検証記録有効なホスト証明書、対応する検証レポート、選択したバックエンドに必要なプラグインとコンテナイメージの記録

リリースを取得する

v0.1.0-alpha.1のwheelとsource distributionはGitHub Releasesから取得できます。

v0.1.0-alpha.1をダウンロード

これらにはHarako-GPU本体のみが含まれます。Parabricks、Dockerイメージ、参照配列、アノテーション、STAR／Salmonインデックスは含まれないため、別途準備が必要です。

新しいcloneからソースを導入する

ソースコードから直接導入することもできます。

git clone https://github.com/do-shima/Harako-GPU.git
cd Harako-GPU
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
harako-gpu --version
harako-gpu doctor --json
harako-gpu ui --no-browser

解析用コンテナと参照データを準備する

  1. 公式ドキュメントに従って、Docker EngineとNVIDIA Container Toolkitを導入します。
  2. 公式のNVIDIA NGCからParabricks 4.6.0-1を取得します。NVIDIAの利用規約は利用者自身で確認して同意してください。Harako-GPUは規約への同意を自動化するコマンドを提供しません。
  3. 必要な公開タスク用コンテナイメージを、指定された識別情報とともに準備します。Runの準備時に各イメージを検証し、不足があれば開始前に停止します。自動的なpullは行いません。
  4. 固定した参照パックとバージョン別インデックスをGitリポジトリの外へ配置します。
  5. 環境管理者が発行したホスト証明書を<runtime-root>/host-profiles/ubuntu_native_rtx3090_ram128_v1.jsonへコピーします。解析計画を作成しても、このファイルは生成・変更されません。
  6. harako-gpu doctor --jsonを実行して利用可能な機能を確認し、科学解析を開始せずに解析計画を作成・確認します。

このリポジトリにはParabricks、参照データ、インデックス、プラグインバイナリー、コンテナアーカイブ、FASTQ、BAMを含めていません。それぞれに個別のライセンスや利用条件が適用されます。

未検証または非対応の構成

まだ検証していない環境

他のUbuntuリリース、RTXモデル、RAM容量、ドライバーバージョン、ストレージ構成、カスタム参照配列を使用するには、別途、事前に検証する必要があります。ハードウェアを検出しただけでは、科学解析を開始できません。

現在の検証済み構成では非対応

固定した64 GBのWindows/WSL環境でのヒト全量BAM生成、CPU STAR、macOSは非対応です。また、NTFS、fuseblk、SMB、CIFS、NFS、WD Gold、/mnt/c、/mnt/d、安全性を確認できないパスを解析中の保存先には使用できません。

利用可否は、検証レポートのハッシュ、コンテナの来歴情報、イメージおよび参照データ・インデックスのチェックサム、実行環境、ローカルファイルシステムの検査結果から判断します。ハードウェアの製品名だけでは判断しません。
