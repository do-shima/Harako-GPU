科学identityをfreezeする小さなNextflow DAG

Harako-nativeが検証済みParabricks alignmentを所有し、共通controllerがversion別定量、validation、matrix、evidenceを担当します。

Harako-native execution

  1. FASTP
    固定image／processed pair。
  2. PARABRICKS_RNA_FQ2BAM
    固定argvとprocess resource。
  3. PUBLISH_ALIGNMENT_CONTRACT
    backend-neutral manifest。
  4. FEATURECOUNTS_BIOTYPE_QC
    GENCODE 49は-t exon -g gene_type。
  5. MULTIQC
    bounded QC/report。

Nextflow内にhidden Salmonはありません。controllerが同じprocessed paired FASTQを明示的library type、6 threadsで定量します。

alignment profile

one-pass workstation

--two-pass-mode None --low-memory --quantMode TranscriptomeSAM GeneCounts --sjdb-overhang 74

exact process: 42.GB、12 CPUs。

two-pass high-memory

--two-pass-mode Basic --low-memory --quantMode TranscriptomeSAM GeneCounts --sjdb-overhang 74

exact process: 96.GB、12 CPUs。

free-form科学arg、global memory override、dynamic escalation、CPU STAR fallbackはありません。

countとquantification

exact GRCh38.p14 / GENCODE 49 packではFeatureCountsをexon/gene_typeに固定します。これはbiotype/QC artifactで、STAR ReadsPerGene.out.tabとは独立です。

Salmon 2.5.1がdeterministic defaultです。Salmon 1.10.3はbounded-numerical compatibility profileとしてvisible/executableです。compare-bothは同一processed FASTQに対して順番に実行し、各Runがimage、index、option、library type、thread数、order、downstream primaryをfreezeします。

Version固定のclaim: Salmonのversionを固定しなければ、software versionに依存する数値差やmethod-dependent variationが、実験条件による差に混入する可能性があります。

ここでいう差は、単純な丸め誤差だけではなく、version、implementation、index、execution behaviorに依存する差を含みます。

immutable lifecycleとreference backend

planはbackend、profile、asset、image、output、resource、execution context、approval identityをfreezeします。prepareはclosureを再検証し、start/resumeはshell=Falseのstructured argv、atomic PID/lock/state、numbered attemptsを使います。completed runはresumeできません。

nfcore_rnaseq_3_26_referenceはpinned pipeline、patch、offline nf-schema@2.5.1、18-image closureを比較用に保持します。Harako-nativeはnf-schemaとfull closureをruntime依存にしません。

制約

  • public research alpha、research-only、non-diagnostic、non-clinical。
  • exact host/referenceのみ。任意RTX/custom reference/general FASTQ claimなし。
  • CPU STAR、DESeq2、matched CPU speed benchmark、全workflow stageがGPUを使うというclaimなし。
  • automatic archive/deleteなし。
  • Ubuntu実browser runtimeは利用不能。AppTest、HTTP、C1 product runはPASS。
  • cross-host equality／biological truthは未評価。
evidenceは固定engineering/scientific contractとretained public inputを検証します。解釈、実験計画、臨床性能、任意deploymentは検証しません。
