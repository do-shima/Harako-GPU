解析手法

解析条件を固定して実行する軽量なNextflowワークフロー

Harako-nativeワークフローが検証済みのParabricksアラインメントとQCを実行し、共通のHarakoコントローラーがバージョン別定量、検証、行列作成、根拠の記録を行います。

Harako-nativeワークフロー

  1. fastpによる前処理
    指定されたコンテナイメージを使い、後続処理に用いる対のFASTQを作成します。
  2. Parabricksによるアラインメント
    PARABRICKS_RNA_FQ2BAMがone-passまたはtwo-passの固定引数と、プロファイルごとに定めた資源を使用します。
  3. アラインメント出力の記録
    PUBLISH_ALIGNMENT_CONTRACTが、バックエンドに依存しないmanifestへ出力を記録します。
  4. FeatureCountsによる生物型QC
    FEATURECOUNTS_BIOTYPE_QCはGENCODE 49に-t exon -g gene_typeを使用します。
  5. MultiQCレポート
    定められたQC結果を集約し、元となる指標へのリンクを示します。

Nextflow内ではSalmonを実行しません。Harakoコントローラーが、同じ前処理済みのpaired FASTQにライブラリタイプを明示し、6スレッドで定量します。このため、選択した各プロファイルの定量は1回だけ実行されます。

アラインメントのプロファイル

one-pass workstation

--two-pass-mode None --low-memory --quantMode TranscriptomeSAM GeneCounts --sjdb-overhang 74

Parabricksの処理にだけ42 GBと12 CPUコアを割り当てます。

two-pass high-memory

--two-pass-mode Basic --low-memory --quantMode TranscriptomeSAM GeneCounts --sjdb-overhang 74

Parabricksの処理にだけ96 GBと12 CPUコアを割り当てます。

利用者が科学的処理の引数や計算資源を自由入力することはできません。メモリを動的に増やす機能やCPU STARへの切り替えもありません。

カウントと定量

固定したGRCh38.p14 / GENCODE 49参照パックでは、FeatureCountsのfeature typeをexon、group typeをgene_typeに固定します。この出力は生物型のQCに用い、STARのReadsPerGene.out.tabによるGeneCountsとは区別します。

Salmon 2.5.1は新しい解析系列の既定です。Salmon 1.10.3も互換性のため選択して実行できますが、反復間で高い一致を示す一方、数値は完全には一致しません。compare-bothでは、同じ前処理済みFASTQに対して2つのプロファイルを順に実行します。

Salmonのバージョンを固定しない場合、ソフトウェアのバージョン、実装、インデックス、実行条件に由来する数値差が、実験条件による差に混入する可能性があります。これは単純な丸め誤差だけを指すものではありません。

Harako-GPUでは各Runについて、Salmonのバージョン、コンテナイメージ、インデックス、オプション、ライブラリタイプを記録・固定します。異なるバージョンで得た結果を、バージョン差を考慮せずに同一系列へ統合しないでください。

Runの進行と参照バックエンド

実行前に、変更不可の解析計画へワークフローのバックエンド、アラインメントと定量のプロファイル、コンテナ、参照データ、出力、計算資源、実行環境、承認ハッシュを記録します。準備時には、これらの要件を再度検証します。開始と再開にはshell=Falseの構造化引数、永続的なPID・ロック・状態ファイル、番号付きの試行を使用します。完了したRunは再開できません。GUIからの詳細な出力検証やサポート用データ作成も、同じサービスを利用します。

参照バックエンドのnfcore_rnaseq_3_26_referenceは、固定したpipeline commit、検証済みpatch、offlineのnf-schema@2.5.1、18個のイメージを比較・専門家向けに維持しています。Harako-nativeはnf-schemaやこの18個すべてのイメージを必要としません。

制約

  • 研究用公開α版であり、研究用途に限ります。診断または臨床用途には使用できません。
  • 記載した実行環境と参照データだけを検証しています。任意のRTX環境、カスタム参照配列、任意のヒトFASTQはまだ検証していません。
  • CPU STARとDESeq2は利用できません。CPU STARとの対応条件をそろえた速度比較は行っておらず、すべての処理がGPUを使うわけでもありません。
  • 自動的な保存や削除は実装していません。完了したRunは、成果物の検証後に利用者が明示的に保存できます。
  • GUIの検証時にはUbuntu上で実際のブラウザーを利用できませんでしたが、AppTest、HTTP検証、GUIからのC1科学解析は合格しました。
  • 異なる実行環境間での同一性と、生物学的な正解は評価していません。
公開している根拠は、記載したワークフロー設定と保持した公開入力を支持します。生物学的な解釈、実験計画、臨床性能、他の環境での動作を保証するものではありません。
