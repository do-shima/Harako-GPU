Harako-GPU

GPU-assisted BAM generation and version-pinned quantification in one GUI

A local, immutable-plan workflow for a narrowly qualified Ubuntu native RTX 3090 / 128 GB host. It produces BAM, junction, GeneCounts, Salmon abundance, matrices, MultiQC, and verification evidence.

GPU-assisted edition

A focused native workflow

Harako-native keeps only the qualified alignment and QC path. The controller performs versioned Salmon, matrices, concordance, artifact verification, and support bundles exactly once.

  1. fastp
    Fixed preprocessing.
  2. Parabricks STAR
    One-pass or two-pass.
  3. Alignment artifacts
    BAM, junction, GeneCounts.
  4. FeatureCounts
    exon/gene_type QC.
  5. Salmon + MultiQC
    Versioned quantification and reports.

Receipt-backed qualified Ubuntu plans default to Harako-native. The full nf-core/rnaseq 3.26 workflow remains an expert/reference backend. Windows/WSL and historical defaults remain the reference backend.

Use Harako-RNAseq when

  • broad Windows/Linux access matters;
  • Salmon, tximport, and DESeq2 are the goal;
  • BAM is not required.

Use Harako-GPU alpha when

  • a qualified NVIDIA GPU host is already available;
  • BAM, junction, and GeneCounts are required;
  • one-pass/two-pass choice or versioned Salmon comparison is useful.

Harako-GPU does not supersede Harako-RNAseq. No matched CPU speedup is claimed because the workflows differ.
