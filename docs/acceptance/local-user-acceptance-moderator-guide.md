# Local acceptance moderator guide

1. Confirm the participant uses an anonymous role code and public fixtures.
2. Explain that product usability—not participant skill—is under evaluation.
3. Read each task without naming the control to use.
4. Do not intervene unless the participant is blocked, requests help, or could
   attempt an unsafe action. Record each intervention and wrong turn.
5. Ask the frozen comprehension questions after Results.
6. Record task completion, elapsed time, wording misunderstandings, navigation
   friction, and issue severity. Timing is diagnostic, not a performance claim.
7. Obtain explicit consent before any screen recording. Without consent, record
   observation notes only.
8. Stop if personal, patient, study, account, or credential data appears.

Do not call a developer walkthrough external acceptance and do not coach a
participant into passing a comprehension question.
