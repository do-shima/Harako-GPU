# Participant instructions

You will use a local research-software prototype with public test data. Work as
you normally would and say when wording or next steps are unclear. This is not
a test of you. Do not enter personal, patient, study, account, credential, or
private research information. The application is for research use only and is
not diagnostic or clinical software.

You may stop at any time. Screen recording is optional and requires separate
explicit consent. Closing the browser does not stop an already active analysis;
the moderator will explain the safe end-of-session procedure.
