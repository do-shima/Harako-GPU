# Local external-user acceptance protocol

Status: `PENDING_EXTERNAL_USERS`.

Recruit, where available, two biomedical researchers without command-line
experience, one RNA-seq researcher, and one technical/bioinformatics user.
Use anonymous role codes only. Use public qualification fixtures; do not use
participant research data, patient data, credentials, or identifiers.

Run tasks A–G in the frozen order: prepare human recommended quantification;
explain blocked human BAM and create a handoff; identify primary/secondary in
compare-both; find gene TPM and the report; create support information and
resume a failed run; reconnect to an existing run; explain artifacts absent
from quant-only. Ask whether GPU and BAM were used, which profile is primary,
the purpose of secondary, why human BAM is unavailable, whether closing the
browser stops a run, and what to do after failure.

Thresholds are fixed before participation: at least 80% unassisted completion
for each critical task; zero unsupported-route launches, silent-fallback
misconceptions, or data-loss actions; at least 80% correct comprehension for
BAM/GPU/primary questions; zero CRITICAL and zero unresolved MAJOR issues.
Do not reinterpret thresholds after observing results.

External acceptance may be declared only from completed anonymous observation
forms and an aggregate report. This repository currently contains no result.
