# GUI navigation

The fixed order is Project, Samples, Reference & capability, Analysis, Review
& prepare, Run, Results, and Recovery & support. Project identity gates sample
editing; validated samples gate reference/analysis; an available capability
gates preparation; and a prepared or reconnected run gates execution/results.

Incomplete runs show status only. FAILED or INTERRUPTED runs expose recovery.
COMPLETED runs expose validated results. Navigation and browser reruns do not
control the child controller. There is intentionally no cancel action.

Each page begins with its single purpose and completion condition; a current
blocker is shown only when one exists. Technical identities stay in expanders
so that the default flow emphasizes route, BAM, GPU, primary profile,
limitation, and next action. Keyboard order follows the same fixed page order.
