This amendment was frozen before any quantification-only result was generated.
It preserves ERR188044, deterministic first-N subsets, product library type U /
Salmon IU, GRCh38.p14/GENCODE 49, both version-specific Salmon indices, and the
registered resource thresholds. It changes only the explicit route to CPU FASTQ
quantification with BAM mode `none`.

Q1 (1M), Q2 (5M compare-both), and Q3 (10M) are required. Q4 and Q5 are
conditional. BAM, STAR, and alignment artifacts are prospectively
`NOT_APPLICABLE`, not missing. The historical two-pass and one-pass failures are
immutable parent evidence and cannot be overwritten by this qualification.
