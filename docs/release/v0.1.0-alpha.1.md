# Harako-GPU v0.1.0-alpha.1 release readiness

Status: **public research alpha candidate**. No tag, GitHub Release, Pages
deployment, container publication, or repository-visibility change is created
by this preparation branch.

## Supported scope

The candidate exposes the receipt-backed Ubuntu native RTX 3090 / 128 GB host
profile, Harako-native one-pass (42.GB / 12 CPUs), Harako-native two-pass
(96.GB / 12 CPUs), fixed GRCh38.p14 / GENCODE 49 assets, Salmon 2.5.1 as the
default, and Salmon 1.10.3 as a bounded-numerical compatibility profile. The
nf-core/rnaseq 3.26 reference backend remains selectable.

## Qualification summary

- Full ERR188044 one-pass and two-pass reached terminal success with verified
  archives on the exact qualification host and assets.
- Harako-native C1 one-pass/two-pass achieved strict scientific and BAM
  record-stream parity with the reference backend.
- Native GUI C1 one-pass/two-pass passed the immutable product lifecycle,
  AppTest, HTTP loopback, deep verification, and sanitized support-bundle gates.
- Salmon 2.5.1/1.10.3 C1 timing and concordance evidence has `n=2` and is
  descriptive only.

## Installation

Install from a fresh clone into Python 3.11+, then provision Docker/NVIDIA,
Java 17+, Nextflow 25.04.3, the exact third-party images, fixed references and
indices, and a validated host qualification receipt. Harako-GPU does not
download or redistribute Parabricks and does not accept NVIDIA terms.

## Upgrade policy

Frozen runs and historical plans retain their stored workflow backend,
profiles, images, reference/index identities, and approval hashes. Never
silently migrate an analysis series across Salmon versions or workflow
backends. A later alpha may change public interfaces; review release notes and
create a new analysis series for contract changes.

## Limitations and warranty

This candidate is research-only, non-diagnostic, non-clinical, and provided
without warranty. It does not qualify CPU STAR, arbitrary hosts/references,

No Parabricks image, Docker layer, plugin binary, reference, index, FASTQ, BAM,
